개인정보처리방침

시행일: 2026-09-28 · 버전 1.1

본 방침은 MetaBook Android 애플리케이션(이하 “본 앱”)에 적용됩니다. 본 앱은 사용자가 직접 준비한 소설·만화 콘텐츠를 읽기 위한 광고 없는 개인용 리더이며, 온디바이스 TTS(텍스트 음성 변환)를 내장합니다.

1. 수집하는 개인정보

본 앱의 개발자는 어떠한 개인정보도 수집하지 않습니다. 계정·로그인·회원가입이 없으며, 이름, 위치, 연락처, 하드웨어 기기 식별자, 광고 ID, 사용 통계, 분석(analytics) 데이터를 수집하거나 개발자 또는 제3자 서버로 전송하지 않습니다.

본 앱은 독서 위치를 기기별로 구분해 저장하는 키로 Android 플랫폼이 앱마다 제공하는 기기 ID(Android ID)를 사용합니다. 이 값은 앱 서명 키·사용자·기기 조합마다 달라 다른 앱과 공유되지 않으며, 앱을 다시 설치해도 유지되어 같은 기기의 독서 기록을 이어 갈 수 있게 합니다(기기 초기화 시 변경). IMEI·전화번호·광고 ID 등 다른 식별자는 사용하지 않습니다. 이 기기 ID는 아래 2항의 “사용자 본인이 지정한 서버” 외에는 어디에도 전송되지 않으며, 개발자는 이를 수신하지 않습니다. (버전 1.0까지는 무작위 UUID를 사용했습니다.)

2. 네트워크 통신 (사용자 지정 서버)

본 앱에는 기본 서버가 없습니다. 네트워크 통신은 사용자가 설정 화면에 직접 입력한 사용자 본인 소유의 서버 주소에 대해서만 일어나며, 서버를 입력하지 않으면 본 앱은 완전히 오프라인으로 동작합니다(기기 내 로컬 책 폴더 읽기).

서버를 지정한 경우 해당 서버와 주고받는 데이터는 다음과 같습니다.

  • 책·만화 콘텐츠 다운로드 (챕터 텍스트, 만화 이미지, 목차)
  • 독서 진행 상태 (책 ID·제목, 마지막 챕터/페이지, TTS 문단 위치, 저장 시각)
  • 리더 설정값 (글꼴 크기, TTS 속도 등)과 1항의 기기 ID (Android ID, 기기별 저장 구분용)

이 전송은 사용자가 스스로 지정한 목적지(사용자 소유 서버)로의 전송이며, 개발자는 이 데이터에 접근할 수 없고 수신하지도 않습니다.

3. 기기 내 저장 데이터

책·만화 캐시, 독서 위치(save_data.json), 설정값, TTS 엔진 파일은 모두 앱 전용 저장소(앱 샌드박스)에 보관됩니다. 로컬 책 파일은 앱 전용 MetaBook 폴더에서 읽습니다. 이 데이터는 외부로 전송되지 않으며(위 2항의 사용자 지정 서버 동기화 제외), 앱을 삭제하면 함께 제거됩니다. 클라우드 백업은 비활성화되어 있습니다(allowBackup=false).

4. 텍스트 음성 변환 (TTS)

TTS 음성 합성은 전부 기기 내부에서 수행됩니다. 읽어 주는 텍스트나 합성된 음성이 네트워크로 전송되는 일은 없으며, 재생에 네트워크가 필요하지 않습니다.

5. 권한

본 앱이 선언하는 권한과 사용 목적은 다음과 같습니다.

  • INTERNET / ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE - 사용자 지정 서버와의 콘텐츠 수신·독서 위치 동기화, 네트워크 상태 확인
  • WAKE_LOCK - 화면이 꺼진 상태에서도 TTS 재생 유지
  • FOREGROUND_SERVICE / FOREGROUND_SERVICE_MEDIA_PLAYBACK - 백그라운드 TTS 재생 및 미디어 알림
  • POST_NOTIFICATIONS - TTS 재생 컨트롤 알림 표시

본 앱은 위치, 연락처, 카메라, 마이크, 공용 저장소 등 어떠한 민감 권한도 요청하지 않습니다.

6. 광고 및 트래커

본 앱은 광고를 표시하지 않으며, 어떠한 광고 SDK, 분석 SDK, 추적 라이브러리도 포함하지 않습니다.

7. 데이터 공유 / 제3자 제공

본 앱은 사용자의 어떠한 데이터도 제3자에게 공유·판매·제공하지 않습니다. 데이터가 기기를 벗어나는 유일한 경로는 사용자가 직접 지정한 사용자 소유 서버뿐입니다.

8. 어린이 개인정보 보호

본 앱은 만 13세 미만 아동을 직접 대상으로 하지 않으며, 아동으로부터 개인정보를 의도적으로 수집하지 않습니다. 본 앱은 어떠한 개인정보도 수집하지 않습니다.

9. 보안

본 앱이 기기에 저장하는 데이터는 Android 표준 앱 샌드박스(다른 앱이 접근 불가) 영역에 보관됩니다. 본 앱은 계정 정보나 민감 정보를 저장하지 않습니다. 사용자 지정 서버와의 통신 보안(HTTPS 사용 여부 등)은 사용자가 입력한 서버 주소의 구성에 따릅니다.

10. 방침 변경

본 방침이 변경될 경우, 변경 사항은 본 페이지에 게시되며 시행일이 갱신됩니다.

Privacy Policy (English)

Effective: 2026-09-28 · Version 1.1

This policy applies to the MetaBook Android application ("the App"), an ad-free personal reader for novels and comics you provide yourself, with built-in on-device text-to-speech.

1. Personal Information We Collect

The developer collects no personal information. There is no account, login, or sign-up. We do not collect or transmit your name, location, contacts, hardware device identifiers, advertising IDs, usage statistics, or analytics data to the developer or any third party.

To keep reading positions apart per device, the App uses the device ID that Android provides to each app (Android ID). It differs for every combination of app signing key, user and device, so it is not shared with other apps, and it stays the same across reinstalls so the same device can pick up its reading history (it changes on a factory reset). No other identifier (IMEI, phone number, advertising ID) is used. This device ID is sent nowhere except the user-configured server described in section 2, and the developer does not receive it. (Up to version 1.0 a random UUID was used instead.)

2. Network Communication (Your Own Server)

The App has no default server. Network communication happens only with a server address you enter yourself in Settings; with no server configured, the App works fully offline (reading books from the on-device local folder).

When you configure a server, the App exchanges with it:

  • Book/comic content downloads (chapter text, comic images, chapter lists)
  • Reading progress (book id/title, last chapter/page, TTS paragraph position, timestamps)
  • Reader settings (font size, TTS speed, etc.) and the device ID (Android ID) from section 1 (to keep per-device saves apart)

This is a transfer you initiate to a destination you own and control. The developer cannot access and does not receive this data.

3. Data Stored On Your Device

Book/comic caches, reading positions (save_data.json), settings, and TTS engine files live only in the app sandbox. Local book files are read from the app-specific MetaBook folder. None of this leaves the device (other than the optional sync to your own server above), and it is removed when the App is uninstalled. Cloud backup is disabled (allowBackup=false).

4. Text-to-Speech

TTS synthesis runs entirely on-device. The text being read and the synthesized audio are never sent over the network, and playback requires no network connection.

5. Permissions

  • INTERNET / ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE - fetch content from and sync reading progress to your own server; check connectivity
  • WAKE_LOCK - keep TTS playback alive while the screen is off
  • FOREGROUND_SERVICE / FOREGROUND_SERVICE_MEDIA_PLAYBACK - background TTS playback and the media notification
  • POST_NOTIFICATIONS - show the TTS playback-control notification

The App requests no location, contacts, camera, microphone, or shared-storage permissions.

6. Advertising & Trackers

The App contains no advertising, no advertising SDKs, no analytics SDKs, and no third-party trackers.

7. Data Sharing

The App does not share, sell, or transmit any user data to third parties. The only path data takes off the device is to the server you configure and own.

8. Children's Privacy

The App is not directed at children under 13 and does not knowingly collect any information from children. The App collects no personal information of any kind.

9. Security

Data stored on your device is kept in the standard Android app sandbox (not accessible to other apps). The App stores no account credentials or sensitive information. Transport security to your own server (e.g. whether HTTPS is used) depends on the server address you configure.

10. Changes to This Policy

Updates to this policy will be posted on this page with a revised effective date.
