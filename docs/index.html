MetaBook

한국어 소설·만화 리더 · 온디바이스 TTS · 광고 없는 개인용 앱

MetaBook은 사용자가 직접 준비한 소설과 만화를 읽는 미니멀 Android 리더입니다. 광고, 로그인, 분석 도구를 모두 덜어내고 읽기와 듣기(TTS)에만 집중합니다. 본인 소유 서버에서 스트리밍하거나, 기기 로컬 폴더에 파일을 넣어 완전 오프라인으로 읽을 수 있습니다.

주요 기능

  • 텍스트 리더 - 페이지 단위 렌더링, 글꼴 3종·12단계 크기, 8가지 색 테마, 본문 검색
  • 만화 리더 - 핀치 줌, 페이지/스크롤 모드, 좌→우/우→좌 읽기 방향(일본 만화)
  • 온디바이스 TTS - 한국어 음성 6종(AI TTS 4 + Power TTS 2), 0.5~2.0배속, 문단 하이라이트, 재생에 네트워크 불필요
  • 백그라운드 재생 - 포그라운드 서비스 + 잠금화면 미디어 컨트롤, 화면 꺼짐 유지, 슬립 타이머
  • 독서 위치 저장 - 챕터·페이지·TTS 문단 단위 자동 저장, 기기별 서버 동기화(선택)
  • 오프라인 - 챕터 텍스트/목차/만화 이미지 디스크 캐시, 네트워크 없이 이어 읽기
  • 라이브러리 - 최근 탭(진행률 카드) + 책장 그리드, 장르 필터·정렬·검색
  • 폴더블 최적화 - Galaxy Z Fold 접힘/펼침 시 위치 유지 재페이지네이션

요구 사양

Android 9+ (API 28), arm64-v8a. Google Play 내부 테스트 트랙으로 배포·업데이트됩니다.
